# Development Plan

The following stages are proposals and may change as the prototype teaches us more.

1. **Setup:** Git repository, conventions, documentation, and initial structure.
2. **Model and rules:** cell types, board definition, game state, illumination, conflicts, clues, and victory.
3. **Fixed board:** display a small example and allow bulbs to be placed and removed.
4. **Core verification:** cover edge cases and rules with tests or repeatable procedures.
5. **Reproducible generation:** configuration, seeds, and level generation that preserves at least one solution.
6. **Prototype polish:** basic visual feedback, restart, and a simple level flow.
7. **Future improvements:** solver, uniqueness checks, difficulty, art, and theme as desired.

Keep each stage small and end it with a clear way to verify the result before starting the next one.
