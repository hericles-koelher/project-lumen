# Project Lumen Visual Style

## Direction

Simple, elegant, and cute. Use rounded shapes, friendly proportions, warm light, and gentle contrast. Keep puzzle information easy to read and use decoration sparingly. Background illustrations use soft hand-drawn shading and subtle paper texture; game symbols and interface icons use clean vector shapes in the same palette.

## Palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#192943` | Outlines, walls, primary text |
| Cream | `#F6EFDF` | Playable cells, panels, light surfaces |
| Sage | `#91AA91` | Secondary surfaces and calm accents |
| Sunlight | `#F5C85B` | Illuminated cells and bulb glow |
| Coral | `#E98268` | Small decorative accents |
| Conflict | `#D9534F` | Rule warnings and conflicting bulbs |
| Muted text | `#647184` | Supporting text on light backgrounds |

These are first-pass sampled/estimated colors based on the concept illustrations. Adjust them together after viewing the game in Godot.

## Typography

Use Nunito for interface headings, buttons, labels, clues, and messages. Prefer regular or medium weights for body text and semibold or bold for headings and numbered clues. Avoid small thin text. The main-menu title uses the separate transparent hand-lettered wordmark with its hanging bulb, restored from the user-approved concept.
